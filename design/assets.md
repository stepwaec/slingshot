# Slingshot — asset index (v1.1)

One row per file in `design/assets/`. All SVGs are hand-authored, self-contained (no scripts, external refs or raster) and use only the palette tokens from `style.md` §2 / the brief. "Anchor" is the point the game positions and rotates. The last column is the gist; exact Canvas code lives in `canvas-notes.md` (§ numbers below).

v1.1 (realism pass) rewrote four files — `star.svg`, `planet-start.svg`, `planet-x.svg`, `starfield.svg`. The three body assets are now `<defs>` (ids prefixed `star*` / `ps*` / `px*`, unique across the three files) plus **one top-level group** with all geometry relative to (0, 0): `<g id="star" transform="translate(200 200)">`, `<g id="planetStart" transform="translate(60 60)">`, `<g id="planetX" transform="translate(120 120)">`. Gradients and masks that need positions use `gradientUnits` / `maskUnits="userSpaceOnUse"`, so a mockup copies the `<defs>` and the group verbatim and only changes the `translate`. Each file's header comment lists every stop, offset, alpha and noise parameter — the SVG is the canon; the Canvas code reproduces it into a cached sprite. The only SVG features beyond v1 are `feTurbulence` / `feBlend` / `feComposite` filters and one alpha mask per planet; Chrome renders all of them (verified headless). Everything else is byte-identical to v1.

## Usage rules

- **Cached sprites (v1.1).** The star and both planets are rendered **once** from their SVG recipes into offscreen sprites and blitted every frame; nothing in them (noise, terminator, rim, streamers, granulation, chromosphere) is ever drawn live. Star sprite: 400×400 at DPR, rebuilt on resize (a fixed-size bitmap that `drawImage` scales; the prototype never zooms past 2×). Planet sprites: (2 · 1.12 r + 4) px square — 81 px start / 72 px X at zoom 1 — at the canvas DPR (2× on retina), rebuilt only when the zoom bucket changes, never on resize (`bucketZoom = 1.25^round(log zoom / log 1.25)`: buckets 25 % apart, flipping ±11.8 % about each centre, residual scale 0.894–1.118). The noise tiles (128 px, seeds 3 / 7 / 11) are built once and kept. Planet X's halo and capture ring are drawn live around its sprite. Build costs: background ≈ 2.5 ms, star ≈ 1.5 ms, planets ≈ 1–2 ms each — once.
- Ship is 22 px long at zoom 1 and never smaller than 12 px on screen (`max(12, 22 · zoom)`); its 1 px outline and the cockpit dot are fixed screen px.
- Only the star and planet X glow (cached gradient sprite and live gradient halo). The start planet's atmosphere rim and the sky's halos are scatter inside fixed envelopes (1.12 r / r 4.5), not glow. Ship, trail, path, arrow and HUD are flat; `shadowBlur` is allowed once, on the result card, never on anything that moves; `multiply` / `soft-light` / `destination-in` run only inside sprite builds.
- Capture ring: r 78 at zoom 1, 1.5 px, dash `[6, 6]`; the dashes crawl at −12 px/s via `lineDashOffset` **and** α pulses 0.35 ↔ 0.70 with radius ±2 px over 2.4 s; locks to α 1 (crawl stopped) on a win. Reset `setLineDash([])` and `lineDashOffset = 0` afterwards.
- Trail: 240 samples, 2 px, α 1 at the ship fading to 0 at the tail; per-segment or chunked alpha, no blur, no glow.
- Predicted path: round dots r 1.5 every 10 screen px, α 0.7, last 20 % at α 0.35, end ring r 6; dot spacing does not change with zoom, and it is never dashed lines (that would read as the trail).
- Drag arrow: tick at 242 · power px from the ship centre, shaft starts 16 px out, head 16 px; head and tick tint through `arrow.power` #3DE0C2 (0 %) → #FFC857 (50 %) → #FF5A5F (100 %), the label stays `ui.textMuted`.
- Thrust flash: two "lighter" triangles behind the hull, no blur, alive 1 frame per thrust tick; absent in every result overlay (engine off).
- Starfield and Milky Way: static, screen-space, no parallax, no twinkle; built once into the background canvas from the seeded rules (`canvas-notes.md` §2), exclusion zones star r 140 / start r 60 / X r 80 minimum (the asset keeps 70 / 100).
- HUD (all five mockups, canvas-notes §10): wordmark baseline (40, 50), mode label (40, 70), "FUEL" at x 1180 baseline 48, percentage right-aligned at x 1400 baseline 48, fuel bar 220×8 at (1180, 56), buttons centred on y 820 (Launch 160×44; [1x][2x][4x] 56×36 + Reset 96×36 with a 16 px gap), telemetry baseline (40, 864); weight 500 on wordmark / mode / FUEL.
- Result overlays: scrim `rgba(5,7,16,0.62)` over the whole scene including the HUD; card 520×232 centred at (720, 450), radius 16, `ui.panel` α 0.92, `ui.border`, 4 px accent bar, title 40 px weight 600, subtitle 16 px, "Fly again" 140×40; card shadow `rgba(5,7,16,0.5)`, blur 16 px (σ 8), offset y 8 — the one `shadowBlur`, drawn once.
- Line widths (ring 1.5, trail 2, dots r 1.5, arrow 2, outline 1, planet limb line 1) and all HUD geometry are screen px; body radii, positions, sprite geometry (0.36 r shade offset, 1.25 r shade radius, 1.12 r rim) scale with zoom.
